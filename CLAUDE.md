# DK CourtFest (courtfest.com)

Event platform for the Dakar street basketball event: React 19 + Vite + Tailwind 4 + TypeScript with a Supabase backend. See README.md for the feature map, DEPLOY.md for hosting and PAYMENTS.md for payments.

## Working rules

- House style: never use the em dash character (U+2014) anywhere: copy, code, comments, docs, commit messages. The deploy workflow fails if it reaches index.html, src, supabase or the docs. Use a comma, a period, a colon (French text keeps a non-breaking space before it), parentheses or a plain hyphen instead; titles and labels use the brand's middle dot separator. To search for or strip the character, use a code point such as chr(8212) or String.fromCharCode(0x2014).
- Every push to main deploys to courtfest.com through GitHub Pages, and Alpha6GitSync commits and pushes each saved file within seconds. For a multi-file change, pause the sync (see ../CLAUDE.md), commit once with a descriptive message, then resume.
- The public site is five pages (/, /evenements, /open-runs, /galerie, /rejoindre) rendered by src/pages/LandingPage.tsx from raw HTML fragments in src/pages/landing: nav and footer are shared (nav.*.html, footer.*.html) and each page has a French and an English body (home, evenements, open-runs, galerie, rejoindre). Copy changes go in both language files; layout changes go in src/pages/courtfest-landing.css (the markup is inline-styled, so responsive rules need !important). Grids marked data-mg collapse to one column under 780px; photo grids marked data-cf-photos get the lightbox.
- Icons: the landing uses inline Lucide-style SVGs (class cf-ic, currentColor strokes, WhatsApp glyph filled) inserted in both HTML files: section labels, Programmes badges, Questions cards, the mobile menu, form fields (.cf-field wrappers), social links, the footer row and the floating WhatsApp button (.cf-wa, shown once the hero is scrolled past). Styles live in the icon block of courtfest-landing.css; add new icons the same way in both files. The Tailwind preflight renders a raw svg as display:block, so an icon placed inside running text needs a rule in that block (a container made inline-flex, or the icon made inline-block like .cf-date), otherwise it drops to the left edge on its own line.
- Local run: npm install, copy .env.example to .env with the public Supabase values from .github/workflows/deploy.yml, then npm run dev (the desktop launch config uses port 3003). Check phone widths from 320 to 414px as well as desktop: the document must never be wider than the viewport, or phones zoom out.
- The Supabase project rvgzydyrsnwcygfshryi is shared with other Alpha 6 products (tables prefixed bebey_, crm_, ct_, fin_). Touch only this app's tables, and apply schema or data changes both as a numbered file in supabase/migrations and through the Supabase migration tool so the repository and the database stay in step.
- Players registered by category (elite men, elite women, veterans, youth, open) live in the rosters table (migration 0013, one row per player and category, tied to an edition) and are managed in /admin/rosters; the 2026 rows were imported from the WhatsApp community groups (migration 0014) with the WhatsApp display name as the name and no phone number yet. Public registration on /register is per player and category and writes to rosters through the register_player RPC (migration 0015: a name already listed for the edition and category is completed, not duplicated). The team form (register_team RPC, tables teams and players) lives at /register/equipe.
- The main event and its date live in several places that must move together: the active editions row in Supabase (the app takes the most recently created row, see src/lib/edition.ts; add a new event as a numbered migration such as 0012), the date line of the event block in src/pages/landing/evenements.*.html, the "next event" line of the Events card in home.*.html, the SportsEvent JSON-LD in index.html, the partner email in src/pages/LandingPage.tsx and the README intro. Current main event: Courtfest Dakar 2026, Sunday 1 November 2026, all day, venue not fixed yet (update the editions row and the same files when it is).
